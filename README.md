# CalendarImage

Carga el HTML adjunto y mantiene una copia privada de calendar.jpg dentro de filesDir. Al iniciar, descarga la imagen desde http://192.168.1.28:8080/calendar.jpg y la muestra desde el almacenamiento interno de la app.

Nota: el HTML original referenciaba /storage/emulated/0/Download/zoom/.c.jpg y zoom.js; aquí se han convertido a recursos internos de la app. Sustituye assets/zoom.js por tu zoom.js real para conservar el zoom.
